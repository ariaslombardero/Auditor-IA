# Registro de fuentes normativas

> Cada corrección normativa del plan se apoya en una fuente oficial anotada aquí con su versión y fecha de consulta.
> Sirve para resolver discrepancias entre auditorías: ante una duda, prevalece la fuente oficial consultada, no el criterio de un modelo.

**Estados:** `cotejado` (texto oficial leído y contrastado) · `parcial` (localizado en fuente oficial; solo se ha leído parte del precepto) · `pendiente` (por cotejar antes de usarlo en una corrección) · `no accesible` (la fuente oficial no permite la consulta automatizada; requiere lectura humana).

**Método de cotejo (05/10/2026):** BOE mediante la API de datos abiertos de legislación consolidada (`/datosabiertos/api/legislacion-consolidada/id/{id}/texto/bloque/{bloque}`); EUR-Lex mediante descarga del HTML oficial en castellano y búsqueda literal del precepto.
